# SQL E-Commerce Sales Analysis

## Project Overview

This project focuses on analyzing an E-Commerce database using SQL and SQLite. The analysis covers customers, orders, products, sales, payments, and order status to generate useful business insights.

## Objectives

- Analyze customer purchasing behavior
- Identify high-value customers
- Analyze product sales performance
- Calculate total and category-wise revenue
- Analyze order trends and order status
- Identify customers with no orders

## SQL Analysis Performed

- Customer analysis
- Order analysis
- Product analysis
- Sales and revenue analysis
- Category-wise revenue analysis
- Top 10 highest-spending customers
- Top 10 best-selling products
- Customers with more than 5 orders
- Customers who have never placed an order
- Payment method analysis
- Order status analysis
